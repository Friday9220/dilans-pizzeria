# Dilan's Pizzeria & Café

Hjemmeside for Dilan's Pizzeria & Café, Jagtvej 92, 2200 København N.

Siden er ren HTML, CSS og JavaScript uden byggetrin. Åbn `index.html` i en browser, eller læg mappen på et hvilket som helst webhotel (fx GitHub Pages).

- `index.html` – forsiden
- `styles.css` – design (farver øverst under `:root`)
- `script.js` – scroll-animationer
- `menu.html`, `menu.css`, `menu.js` – menu med kurv og bestilling til afhentning
- `menu-data.js` – alle retter og priser (ret priser her)
- `assets/img/` – billeder fra restauranten

Priser og frokosttilbud er skrevet af fra menukortet (`assets/img/menu.jpg`).
